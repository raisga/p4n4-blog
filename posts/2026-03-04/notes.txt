  ---
  How it all fits together:
  
  1. Sensors publish data over MQTT to Mosquitto
  2. Node-RED routes that data into InfluxDB; Grafana visualizes it
  3. n8n pulls from InfluxDB, feeds queries to Ollama (local LLM) and
   Letta (AI agent) for intelligent analysis and automation
  4. Edge Impulse runs ML inference directly on raw sensor data at
  the edge (independent path)
  5. All three stacks share p4n4-net — the IoT stack owns it, the
  others attach to it
  6. The CLI (p4n4 init / up) scaffolds and orchestrates everything
  7. The REST API + Dashboard expose data to end users
